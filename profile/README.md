# Genstat — ANOVA for a designed experiment you run

Genstat keeps one named experiment job on the desk: the live factors, the ANOVA step in front of you, and a short note the next modeller can read. Extra designs wait for their own title.

## Session Card

| Slice | What you do in Genstat | What remains |
|-------|------------------------|--------------|
| Arrival | Open Genstat and name today's designed job | A titled experiment |
| Focus | Keep only live factors on the Genstat board | A short factor list |
| Check | Read the Genstat tables before a large change | A confirmed ANOVA set |
| Handoff | Mark finished runs inside Genstat | A note for the next design |

## How Genstat Sits

Genstat does not replace the field notebook or the files you already keep. It sits beside them as a named research desk for one designed experiment you run: which factors are open, which tables are pinned, and what the next modeller should read.

If two people share a PC, each keeps a Genstat style of their own. The job stays small on purpose. Extra designs wait for their own title instead of crowding the live ANOVA. A first visit should be one short factor model, then the same Genstat board the next day.

## Traffic Light

| Signal | On the Genstat board | What you do |
|--------|----------------------|-------------|
| Green | Named job, short factor list | Continue the same experiment |
| Amber | Factors from two designs mixed | Split the set before a large change |
| Red | No title, mixed notebooks | Stop and name the Genstat job first |
| Clear | Handoff written, factors few | Close Genstat and leave the desk |

## Open Order

1. Open the last Genstat session, not a new empty job.
2. Read the factor list and the last handoff.
3. Finish one visible ANOVA step inside Genstat.
4. Write what changed, then close with fewer loose tables than you found.
5. If the set feels crowded, drop anything that belongs to a different Genstat design.

## Desk Fit

| Who | What Genstat holds |
|-----|--------------------|
| Field trial | Designed factors you run and the next ANOVA |
| Research desk | Statistical tables kept with the same job |
| Shared bench | One Genstat profile per person |
| Teaching | Demo designs out of the live experiment pile |
| Support | A repeatable Genstat layout for the same factor set |

## After a Week

A week of Genstat jobs is the same design, not a thicker notebook. It is the same title, a shorter factor list, and a note that still makes sense on Monday. Take finished runs off the live set so the next visit starts on the experiment that is still open.

## Sign-off

- [ ] The Genstat job name is short enough to scan
- [ ] Only live factors you run are on the board
- [ ] A second person can read the handoff
- [ ] The last Genstat session still opens after a restart
- [ ] Finished designs are off the live Genstat set

## Field Note

Genstat stays honest when the ANOVA still names the same factors. Name the job, keep the live design, finish one visible table, and write what changed. Extra experiments wait for their own title. Open the last Genstat session and continue.
